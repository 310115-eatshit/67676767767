# 自由城市探索遊戲計畫

## 願景

打造一款寫實風格的開放世界城市探索遊戲。玩家可以自由決定每天要做什麼，在城市與周邊地區移動、探索環境、認識居民、逛店或參與支線事件。整體氛圍參考《俠盜獵車手：聖安地列斯》的廣闊城市與自由探索感，但城市、角色、故事與內容都將另行創作。

犯罪題材可作為虛構遊戲劇情的一部分，著重於角色選擇、故事發展及遊戲內後果；不以現實可照做的犯罪方法為內容目標。

## 核心方向

- **風格**：寫實、現代城市生活感。
- **自由度**：玩家自行選擇探索路線與活動，不強制沿著單一主線遊玩。
- **世界**：城市與周邊區域有不同景觀、店家、居民和事件。
- **玩法構想**：步行或開車移動、探索地點、逛店、與角色互動、參與支線事件，以及選擇是否投入虛構犯罪劇情。
- **選擇後果**：角色行動可能影響居民信任、警方關注、故事發展或可接觸的機會。

## 初步地圖構想

| 區域 | 初步特色／活動方向 |
| --- | --- |
| 市中心 | 熱鬧街道、店家、較多人物與事件 |
| 住宅區 | 居民與日常生活場景 |
| 工業區 | 工業景觀，可探索並考慮加入賽車等活動 |
| 海邊 | 休閒場所與沿岸探索 |
| 郊區 | 城市外圍景觀與較開闊的探索空間 |

原型目前以「新港市」作為虛構城市名稱。以上街區配置為可玩的概念草圖，實際規模與細節尚未定案。

## 路線圖

### 目前狀態

- **階段**：早期可玩原型。
- **進度**：已有中文介紹頁與俯視角街區散步原型，支援鍵盤、觸控方向鍵與點擊移動，包含碰撞、五個可探索地點、拍照收集、居民支線及虛構街頭事件。已實作照片、素描本支線、信任、事件選擇與警方關注的本機保存；街頭事件「跟上搶包者」分支已驗證，另一選項尚待完成乾淨存檔下的流程驗證。地圖新增主要街道名稱提示。GitHub Actions 部署流程已推送，但 Pages 尚未啟用，首次部署待確認。
- **原型決策**：先以純 HTML、CSS、JavaScript 和 Canvas 製作瀏覽器版，方便直接用 GitHub Pages 試玩；新港市為暫定虛構名稱。
